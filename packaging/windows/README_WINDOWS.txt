🌴 TIKI KARAOKE LOUNGE — WINDOWS HOME & PARTY EDITION (v1.0.9) 🍹
================================================================================

Aloha! Welcome to Tiki Karaoke Lounge, the turnkey, zero-install-for-guests
karaoke stage, fair queue manager, and live vocal DSP system for Windows.

--------------------------------------------------------------------------------
1. QUICK START GUIDE
--------------------------------------------------------------------------------

A. INSTALLER EDITION (TikiKaraokeSetup-Pro-1.0.9.exe):
   1. Double-click the installer executable to install.
   2. Launch "Tiki Karaoke Lounge" from your Desktop or Start Menu.
   3. The native Desktop Control Hub and Setup Wizard will open automatically.

B. PORTABLE ZIP EDITION (TikiKaraoke-Pro-Windows-v1.0.9-Portable.zip):
   1. Extract the ZIP folder anywhere on your computer (e.g., C:\TikiKaraoke).
   2. Double-click TikiKaraoke.exe to launch. No administrative installation required!

--------------------------------------------------------------------------------
2. SYSTEM REQUIREMENTS & HARDWARE
--------------------------------------------------------------------------------
- OS: Windows 10 or Windows 11 (64-bit)
- Display: 1 or 2 Displays (Dual-monitor recommended: Host screen + TV Stage display)
- Audio: Built-in speakers, HDMI/TV audio, external PA mixer, or USB Audio Interface
- Microphone: Any USB microphone, wireless dual-mic receiver, or 3.5mm line-in
- Network: Local Wi-Fi router or Windows Mobile Hotspot (Offline LAN supported)

--------------------------------------------------------------------------------
3. HOW IT WORKS
--------------------------------------------------------------------------------

🎛️ 1. DESKTOP CONTROL HUB & SYSTEM TRAY:
   - Displays live server status, scannable Guest & Host QR codes, "Now Singing"
     status, and a collapsible real-time server log.
   - 1-Click buttons to open the Host DJ Desk, TV Stage Display, Smart Media
     Importer, CD+G Optical Disc Ripper, and Setup Wizard.
   - Minimizes cleanly to the Windows System Tray when closed.

📺 2. THE STAGE DISPLAY (TV / Projector):
   - Opens on your chosen TV/monitor in borderless fullscreen or windowed mode.
   - Plays MP4/WebM/MKV video tracks and native CD+G (.cdg + .mp3 / .zip) graphics
     with 4 live visual themes and audio-reactive neon Tiki stage effects.
   - Displays a dynamic QR code for singers to scan with their smartphones.
   - Automatically plays intermission Sing-Alongs or Music Videos when idle!

📱 3. SINGER SMARTPHONE JOIN (Zero App Install):
   - Guests scan the QR code on the TV stage or printable 3D Table Tents.
   - Works instantly in mobile Safari, Chrome, Firefox, or Edge.
   - Singers choose their nickname (or roll a random Tiki Persona) and avatar.
   - Fair Round-Robin queue automatically balances turns across all singers.
   - Features Key/Pitch shifting (-3 to +3 semitones), Duet joining, Song
     Dedications, Private Rehearsal preview, "You're Up in ~30s" alerts, and
     downloadable Souvenir Live MP3 Recordings with custom 45 RPM Vinyl Album Art!

👑 4. MASTER HOST DJ DESK & 3-MODE MIC ROUTING:
   - Control from your PC or unlock on your smartphone via the 4-digit Host PIN.
   - 3 Microphone Monitoring Modes:
     • Hardware Direct: Zero-latency bypass for external mixers/audio interfaces.
     • Native OS Loopback: Ultra-low-latency WASAPI shared-mode routing via the
       bundled tiki-mic-router.exe helper.
     • Browser WebRTC DSP: Dual-singer (L/R) vocal compressor, 90Hz high-pass,
       warm plate reverb, dual VU meters, and automatic between-song BGM ducking.
   - Venue A/V Sync (-300ms to +500ms) aligns HDMI TV lag or Bluetooth speakers.

--------------------------------------------------------------------------------
4. MEDIA IMPORT, CD+G RIPPING & CURATED OFFLINE MODE
--------------------------------------------------------------------------------

A. Curated Local Library Mode (Strict BYOM Lock):
   - Enable in the Host DJ Desk to disable online stream searches/downloads and
     restrict singer requests strictly to your imported local media library.

B. Smart Media Importer & CompuHost Migration:
   - Launch "Import Media" from the Desktop Control Hub or Setup Wizard.
   - Automatically sanitizes filenames, enriches release years, measures EBU R128
     loudness (-16.0 LUFS target), and imports MP4, MKV, WebM, MP3+CDG, and ZIP
     archives, or migrates CompuHost V3/V4/V5 SongList.tps databases in 1 click.
